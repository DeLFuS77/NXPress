The license covers the code, not the name or the logo. As additional terms under section 7 of the license, which apply to this program and to every version derived from it:

1. **The name and the logo are not licensed** (section 7, paragraph e). "NXPress" and the logo of NXPress are kept for the versions published at https://github.com/DeLFuS77/NXPress. A modified version must be given another name and another logo.
2. **A modified version must say it is one** (section 7, paragraph c). It must not present itself as NXPress, or as a version published by the author of NXPress. Saying that it is based on NXPress, with a link to this repository, is welcome.
3. **The author is named** (section 7, paragraph b). A modified version that has a window keeps, where it tells who makes it, the notice "Based on NXPress by DeLFuS77" with a link to https://github.com/DeLFuS77/NXPress, and the notice of who makes NXPress and its license that NXPress shows in Settings › Help › Code and license.

These terms do not limit anything else the license allows: a modified version can be built, used and shared as the license says, under its own name.

## Official versions

The versions of NXPress are built by the workflow of this repository from a tag, and their checksums (SHA256SUMS.txt) are signed with the key of NXPress (SHA256SUMS.txt.minisig). NXPress tells in its window when the program running is not one of them.

Only that workflow builds NXPress with its name and its logo (the build tag `official` and `build/winres`). A program built from this code in any other way is an unofficial build: its window is called "NXPress (unofficial build)", it has a plain icon, and it tells in its side menu that it is not an official version.

Problems with a modified version go to whoever made it: the issues and the Discord server of NXPress are for the official versions.
